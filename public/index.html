Required: sku, name, category, stock, reorder_level, price. Up to 2,000 products; non-negative numbers; one currency per file. Prices have two decimal places. Demo uses INR.

Method and scope
  1. Normalize case, spacing and terminal punctuation.
  2. Match a complete language pattern to an intent.
  3. Extract and validate category, numeric, comparison and ranking slots.
  4. Create a typed query plan and apply it to the local table.

No LLM or learned model. The SQL shown is an equivalent parameterized preview; the browser executes the same typed plan in JavaScript. Only read operations are supported. No sales forecasts, date filters or arbitrary SQL.
